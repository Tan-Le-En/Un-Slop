# REFACTOR workflow

1. List what must be preserved: purpose, essential content, identity (logo, colours, voice), constraints, structure the user relies on.
2. Audit quickly (auditing.md steps 1-4), but stop at a ranked list.
3. Change in order: truth and function, hierarchy, clarity, consistency, craft, originality. Smallest effective change first.
4. Do not redesign what is not broken. If a larger redesign would help, propose it separately.
5. Keep a change log (what, why) and a list of preserved items.
6. Run FINAL QC. Compare before and after against the same rubric.
