# FINAL QC checklist

Run before saying anything is done. Fix, then re-check.

**Truth and constraints**
- [ ] Every fact, number, name, quote and credit came from the user or a cited source.
- [ ] Required rules, limits, language and format are met.
- [ ] No placeholder or assistant residue left.

**Function**
- [ ] Works end to end (links, forms, interactions, export).
- [ ] Mobile width, 200% zoom, keyboard only, grayscale.
- [ ] Contrast AA; colour never alone; alt text; focus visible; reduced motion respected.
- [ ] Print or export checked at final size and resolution.

**Communication**
- [ ] Squint test passes; focal point clear; 3-second read works.
- [ ] Main message stated plainly and early.
- [ ] Text sweep done (writing-excellence.md section 2).

**Craft**
- [ ] Spacing, alignment, radii, icon weight, type scale all consistent.
- [ ] Defaults challenged: font, palette, layout, phrasing each justified.
- [ ] Every decorative element has a stated purpose or is gone.
- [ ] Typographic marks correct; no widows or stray orphans.

**Score**
- [ ] Rubric applied with evidence; critical failures cleared; remaining weaknesses listed honestly.
