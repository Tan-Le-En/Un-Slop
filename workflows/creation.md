# CREATE workflow

1. **Brief.** Capture audience, purpose, medium, tone, content, constraints, success criteria. Read any rubric or competition rules. Ask at most one question if something blocks progress; otherwise state assumptions.
2. **Concept.** One sentence concept plus the thing the reader should notice first. Name the three most probable default choices for this brief (font, colour, layout, phrasing) and decide for each: keep with a reason, or replace.
3. **System.** Write tokens before building: type scale, spacing scale, palette roles, grid, radius and shadow rules (or "none"), voice notes for text.
4. **Content.** Draft real content first (or honest placeholders). Run writing-excellence.md on all copy. Never invent facts.
5. **Build.** Structure, then type, then colour, then detail. Add motion and decoration last and only with a reason.
6. **Decisions note.** Three to six lines: concept, type, colour, layout logic, what was left out and why.
7. **FINAL QC.** Run workflows/final-quality-control.md. Fix, then deliver.

Do not generate a generic draft and decorate it. If the first draft is a template, restart from step 2.
