# THE UNSLOP FRAMEWORK

Contents: pillars 1-8, then sub-frameworks A-F.

Each pillar: principle, failure patterns, exceptional execution, rules, example, evaluation test, exceptions.

## 1. Authenticity
Principle: output carries a point of view, specific detail and a consistent voice.
Failures: regression to the mean (generic statements that fit any subject); puffery ("pivotal", "testament", "rich tapestry"); template phrasing; stock imagery and emoji as meaning; fake social proof.
Exceptional: could only have been written or designed for this subject. Contains a detail a generic generator would not produce.
Rules: replace each abstraction with a concrete noun, number (user-supplied) or example. Cut claims of importance and let facts carry it. Vary rhythm. Use the brief's own vocabulary.
Before: "The festival plays a pivotal role in fostering community." After: "Four hundred stalls close the street on Friday night, and some families have run the same ones for decades." (Only if those facts are supplied.)
Test: swap the subject for another. If the text or design still works unchanged, it fails.
Exception: legal, safety and technical text should be plain and formulaic on purpose.

## 2. Intentionality
Principle: every element has a reason that can be stated.
Failures: decoration, gratuitous gradient, shadow, glass, animation, icon rows, filler sections, summaries that repeat.
Exceptional: removing any element loses something.
Rules: write a one-line reason per major element during CREATE. Delete what has none. Motion only to show cause, state or continuity.
Test: "What does this do for the reader?" Unanswerable means cut.
Exception: ornament is legitimate when the brief is ornamental (festival, jewellery, children's book); then it must be consistent and own the concept.

## 3. Visual Excellence
Principle: composition, type, colour and hierarchy work as one system.
Failures: no focal point; everything bold; weak colour relationships; mixed illustration styles; random alignment.
Exceptional: eye path is obvious; a restrained palette with dominant, support and accent roles; scale contrast large enough to be unmistakable.
Rules: define type scale, spacing scale and palette roles before layout. Use at most two type families unless the concept demands more. Align to a grid; break it on purpose and once.
Test: squint test and 3-second test (what is it, what do I do next).
Exception: maximalist work still needs a hierarchy, usually through repetition and a dominant element.

## 4. Clarity
Principle: the message is understood fast and correctly.
Failures: excess text; vague labels ("Solutions", "Learn more"); charts needing a legend lookup; jargon; buried key fact.
Exceptional: the main message is stated plainly at the top; each unit has one job.
Rules: lead with the point. One idea per paragraph, slide, card or panel. Label directly on charts. Plain words over impressive ones.
Test: can a stranger state the main point after 10 seconds?
Exception: art and exploratory pieces may reward slow reading; say so.

## 5. Originality
Principle: choices fit this brief rather than the most common answer.
Failures: SaaS template (centred hero, three cards, purple-blue gradient, Inter); trend copying; identical section rhythm.
Exceptional: one unmistakable idea (a grid logic, a typographic voice, a colour story, a metaphor from the subject) applied consistently.
Rules: list the three most probable choices for the brief, then decide consciously whether to keep each. Source metaphors from the subject matter. Do not chase novelty; unusual and wrong is still wrong.
Test: would this be confused with ten other outputs for similar prompts?
Exception: conventions help users (nav at top, checkout flows). Be original in expression, conventional in usability.

## 6. Craftsmanship
Principle: details are exact.
Failures: inconsistent radii, margins, icon weights; orphaned words; stretched images; mixed quote styles; off-by-a-few-pixels alignment.
Exceptional: invisible consistency.
Rules: tokens for spacing, radius, colour, type. Optical alignment. Proofread. Check every state (hover, focus, empty, error, long text, small screen).
Test: zoom 200% and inspect edges; look for any element that does not obey the system.

## 7. Functionality
Principle: it works for the person using it.
Failures: dead links, non-responsive layout, contrast failure, keyboard traps, motion that cannot be turned off, unreadable at print size.
Rules: semantic HTML, visible focus, 44px targets, prefers-reduced-motion respected, alt text, print size and resolution checked.
Test: use it. Tab through it. Open it at phone width. Print or export it.

## 8. Contextual Intelligence
Principle: audience, purpose, medium and constraints decide everything else.
Failures: corporate tone for a children's science fair; dense academic layout on a phone; one style for every job.
Rules: record audience, reader state (rushed, expert, anxious, delighted), medium (screen, print, projection, distance), tone, and hard constraints (brand, rubric, word limits, language). For competition work, read the judging criteria first and design to them.
Test: does a member of the actual audience feel addressed?

# Sub-frameworks

## A. Writing and editorial
Start with the point and the reader. Draft in plain concrete prose, then run the pattern sweep in writing-excellence.md. Voice comes from specificity and rhythm, not quirks. Fact-check every claim; keep the user's facts, never add new ones.

## B. Websites and interfaces
Task and content first, then structure, then type and colour, then components, then motion. See website-design.md. Reject template layouts unless the content justifies them.

## C. Posters, infographics, graphic design
One focal point, one message, a grid, restrained type, minimal text, honest data. See poster-design.md.

## D. Presentations
One idea per slide, headline as a claim, visual evidence, consistent master. See presentation-design.md.

## E. Branding and visual identity
A concept (what the brand believes, in one sentence), then a wordmark or type voice, palette with roles, a pattern or motif system, tone-of-voice rules, usage limits. A logo is not an identity. Avoid generic abstract marks (swoosh, hexagon, gradient orb) unless the concept justifies them. Check at 16px, in one colour, and in black on white.

## F. General creative and professional deliverables (reports, CVs, emails, forms)
Structure for scanning: informative headings, short paragraphs, consistent lists, tables only for comparisons. Use real hierarchy in document styles. Remove ceremony (long openers, restated conclusions). Match tone to the recipient.
